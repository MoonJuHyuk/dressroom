## 동작 구조

```
폰/PC 브라우저 (GitHub Pages의 앱 화면)
   ├─ 저장·목록 → Apps Script 웹 앱 (연결 링크 속 비밀키로 보호)
   │                 ├─ 시트 Items 탭에 한 줄씩 저장
   │                 └─ 사진은 드라이브 'Dressroom 사진' 폴더
   └─ (선택) 모델명 검색·매장 비교 → Claude API
```

- 두 사람이 같은 연결 링크로 연결하면 같은 옷장을 봅니다. 앱 설정 → **다른 기기 연결 링크 보내기**.
- 링크가 새어 나가면 Apps Script에서 `resetSecret` 실행 → `connectLink`로 새 링크 발급.

## 화면과 기능

- 홈 '코디' (v0.3.0, 기본): 사람 실루엣 위 부위별 칸(모자·안경·목도리·티셔츠·자켓·시계(그림 속 사람 왼손목=화면 오른쪽)·가방(화면 왼쪽 손 옆)·바지·양말·신발). 칸을 좌우로 밀어 옷 바꾸기, 맨 끝은 '안 입음', 섞기, 빈 칸 ＋는 그 종류로 등록. 고른 조합은 기기에 기억(dr.fit). 위치는 app.js `FIT_SLOTS`
- 홈 '목록': 10개 종류(모자·안경·목도리·티셔츠·자켓·시계·가방·바지·양말·신발) 타일, 주인 필터(전체/주혁/모카/공용 — 개인 필터에는 공용도 함께 표시)
- 등록: 사진 여러 장(찍기/앨범), 종류·주인·브랜드·모델명·이름·색상·소재·사이즈·구매시기·금액·마지막 착용일·메모
- 모델명으로 정보 찾기: 찾은 값을 **제안만** 하고 적용은 직접. 입력된 값은 덮어쓰지 않음
- 라벨 찍어서 찾기 (v0.2.0): 택·케어라벨 사진의 글자(브랜드·품번·사이즈·혼용률)를 읽고 품번으로 검색해 제안. 라벨 사진은 옷 사진 맨 뒤에 함께 저장
- 상세: 사진 넘겨보기, **오늘 입었어요**(마지막 착용일·횟수 기록), 수정, 삭제
- 매장에서 비교: 사진+종류 → 집의 같은 종류 바로 표시, AI 비교 시 비슷한 옷/같이 입기 좋은 옷
- 오래 손이 안 간 옷: 마지막 착용일(없으면 구매시기·등록일) 기준, 1년 넘은 옷 모음

## 파일별 역할

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `css/app.css` | 디자인: v0.4.0부터 Noir Maison(흑백·얇은 선·대문자 자간). 배경 색 6가지는 `html[data-bg]` 토큰(맨 아래 블록), 고른 색은 기기마다 저장(dr.bg) |
| `js/app.js` | 화면 동작 전부. 맨 위 `VERSION`, 종류 목록 `CATS`, 기본 주인 이름 |
| `js/ai.js` | Claude 지시문 (모델명 찾기, 매장 비교) |
| `js/store.js` | 저장소 연결 (구글시트 / 이 기기) |
| `sw.js` | 오프라인·업데이트. `VERSION`을 app.js와 같이 올려야 폰이 새 파일을 받음 |
| `apps-script/Code.gs` | 시트 저장 스크립트 원본 (실제 편집기 쪽에는 WEB_APP_URL이 채워져 있음) |

## 고칠 때 순서

1. 앱만 고칠 때: 파일 수정 → `VERSION` 두 곳 올리기 → GitHub에 올리기 → 1~2분 뒤 반영
2. 시트 칸을 추가할 때: `FIELDS` 맨 뒤에 추가 → 편집기 저장 → 시트에 열 추가 → **배포 관리 → 같은 배포를 새 버전으로** → 앱 수정
