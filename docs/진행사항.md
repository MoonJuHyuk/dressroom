# Dressroom 진행사항

새로 이어서 작업할 때 이 문서와 `작업안내서.md`부터 읽으세요.

## 작업 방식 (주인 요청)
- 요청을 받으면 바로 고치지 말고, **무엇을 어떻게 바꿀지 정리해서 보여주고 확정을 받은 뒤** 작업한다.
- 화면을 바꿀 때는 먼저 **이미지 시안**으로 확인받는다.
- 브라우저·PC에서 할 수 있는 설정(시트, Apps Script, GitHub)은 직접 처리하고, 구글 권한 허용처럼 본인만 할 수 있는 것만 요청한다.

### 설정 상태
- 구글시트 **Dressroom**(내 드라이브), 탭 `Items` · `요약` · `연결`(연결 링크)
- Apps Script 프로젝트 **Dressroom**, 웹 앱 배포 버전 2 (2026-11-09 15:53, 미리보기 1600px 반영)
- Claude API 키: 시트 스크립트 속성에 저장됨 (Console 조직 *Moon's Individual Org*, 키 이름 `dressroom` 예정 — 주인이 직접 입력)
- 연결된 기기: 주혁 폰(삼성 인터넷 설치 앱), PC 크롬
- 주혁 폰은 크롬의 앱 설치가 꼬여 있어 **삼성 인터넷**으로 설치함 (카드 정산 앱 때와 같은 현상). 설치 앱은 브라우저와 저장 공간이 따로라 앱 안에서 한 번 더 연결해야 했음

### 알아둘 점
- 시계 칸은 "그림 속 사람의 왼손목" = 화면 오른쪽에 둠. 화면 기준 왼쪽을 원하면 `FIT_SLOTS`의 watch 위치만 바꾸면 됨
- 크롬 사이트 데이터 삭제는 하지 말 것 — 같은 주소의 술곳간·카드 정산 연결까지 풀림
- 라이브 Code.gs의 `CATS`(요약용)는 예전 9개 그대로지만, 요약 탭은 시트에 직접 10줄로 고쳐 둠. setup을 다시 돌릴 일이 있으면 repo의 Code.gs를 붙여넣고 실행
